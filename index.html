專案需求規格書 (PRD)

1. 專案名稱與核心概念

專案名稱：神秘學 AI 塔羅靈魂占卜 Web App (Mystic Tarot Synthesizer)

核心概念：結合 3D 視覺翻牌動畫、HTML5 Canvas 互動星空、Web Audio 原生頌缽聲學合成與 LocalStorage 占卜日誌的沉浸式線上塔羅牌系統。

2. 目標使用者與使用情境

  • 探索內心與尋求解答者：在面臨人生選擇、情感困惑或工作壓力時，隨時透過線上塔羅尋找靈感與啟示。
  • 每日運勢抽牌者：每天早上抽出單張牌作為當天的靈魂指引與心理暗示。
  • 沉浸式體驗愛好者：享受具備音效、星空粒子與 3D 翻牌動畫的微互動網頁。

3. 功能矩陣與技術實現

功能模組 細節描述 技術實現
三大靈魂牌陣 單牌指引、三張牌陣（時序）、四元素牌陣。 JS DOM Dynamic Render
22 張大牌庫 包含正位與逆位隨機邏輯、愛情/事業/心靈獨立解析。 JS Tarot Dataset & Random Math
3D 動態翻牌 懸停放大、點擊洗牌與 3D 180度翻牌動畫。 CSS 3D Perspective & RotateY
原生頌缽音效 免載入外部 MP3，使用演算法即時合成西藏頌缽音效。 Web Audio API (OscillatorNode)
占卜日誌儲存 輸入問題與結果完整保存於瀏覽器，可隨時查閱。 Browser LocalStorage API

4. AI Vibe Coding 疊代紀錄

本專案全程透過 AI 協助開發，經歷了 4 個主要階段：發想與規格定義 -> 卡牌資料庫與 3D 視覺開發 -> Web Audio 頌缽音效加入 -> LocalStorage 占卜日誌與單一 HTML 檔案打包，確保託管於 GitHub Pages 時 100% 可順暢開啟運作。
